Put the chosen mod JAR and matching Fabric API in that instance's mods folder.
Replace its older gamblingmenu JAR; do not install multiple variants together.
This folder does not include Fabric Loader or Fabric API. All builds are Fabric,
client-side, for Minecraft Java Edition. No Prism instances have been modified.

Right Shift opens/closes the GUI; Escape closes it; F5 switches camera normally.
Settings > Edit HUD positions moves Auction and Profit Tracker previews. Positions
save automatically. All versions include the same payment, blacklist, multipliers,
auction and profit tracker features, bundled Inter fonts and GUI assets.

All three new ports passed builds, exact-money/auction/profit tests, and real
Minecraft client tests on Linux using OpenGL. GUI/font rendering, F5/Right Shift,
Escape, settings, HUD dragging/resizing, auctions/confetti, payments/refunds,
multipliers and profit exclusions were checked. Economy receipts were simulated
in isolated worlds; no public-server payments were made. Windows and Vulkan
were not executed here. The original 1.21.11 JAR is the previously tested release.
